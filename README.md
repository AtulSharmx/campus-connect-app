# Campus Connect: Android app

Public download for the Campus Connect app. **This repository holds the APK and nothing
else.** No source code, no configuration and no data. The project source is private.

## Install

Download `campus-connect.apk` from [Releases](../../releases/latest), or go to
[campusconnets.in/download](https://www.campusconnets.in/download/).

Campus Connect is not on Google Play, so Android will ask you to allow the install the
first time. Open the downloaded file, allow installs from your browser, then confirm.

Requires Android 7.0 or newer.

To check you got the file intact:

```
sha256  97aab3bde71c8884944bf493b4c2060fe1203593648f770d69f3f97cc9319c13
```

## What it is

An app for SGT University students: clubs, notices, polls, Lost & Found, campus places, a
teammate finder, and Ask Me, a helper that answers in English, Hindi or Hinglish from
checked information only.

Built by a team of three students, funded by ACIC SGT University.

## Before you sign up

**This build does not verify your phone number.** It is a demo release: the signup code is
always `123456`, no SMS is sent, and nothing checks that the number you type belongs to
you. The app says so on the screen where it asks. Do not treat an account here as proof of
anyone's identity.

Campus Connect is a student project. It is **not** an official university system, it is
not endorsed by SGT University, and it has no access to university student records.
